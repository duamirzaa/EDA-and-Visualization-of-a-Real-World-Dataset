# EDA-and-Visualization-of-a-Real-World-Dataset
This project involves Exploratory Data Analysis (EDA) and Data Visualization of a real-world dataset to uncover hidden patterns, trends, and insights. The goal is to understand the data better before building any predictive models, and to communicate findings through effective visualizations.
# 🚢 EDA and Visualization of Titanic Dataset


---

## 📌 Project Objective

- Understand the structure and contents of the Titanic dataset.
- Analyze key features such as age, gender, passenger class, fare, etc.
- Visualize survival patterns and correlations between features.
- Clean and prepare the data for future predictive modeling.

---

## 📂 Dataset

The Titanic dataset contains information about passengers such as:

- **Survival** (0 = No, 1 = Yes)
- **Pclass** (Ticket class)
- **Sex**
- **Age**
- **SibSp** (Number of siblings/spouses aboard)
- **Parch** (Number of parents/children aboard)
- **Fare**
- **Embarked** (Port of Embarkation)

Dataset Source: [Kaggle - Titanic: Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic/data)

---

---

## 📊 Key Analysis Performed

- Data cleaning (handling missing values, converting data types)
- Descriptive statistics
- Survival rate comparison by:
  - Gender
  - Passenger class
  - Age groups
  - Embarkation port
- Correlation heatmap
- Bar plots, histograms, pie charts, and box plots

---

## 📁 Project Files

- `Titanic_EDA.ipynb` – Jupyter Notebook with all analysis and visualizations
- `titanic.csv` – Dataset used for analysis
- `README.md` – Project documentation

---

## ✅ Summary of Findings

- Female passengers had a significantly higher survival rate.
- Passengers in higher classes (1st class) had better chances of survival.
- Children (under 10) also had a better survival rate.
- Embarkation point and fare also showed some correlation with survival.
